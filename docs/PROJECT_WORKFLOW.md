# د Movie Studio v2 کاري بهیر

دا پروژه د لاسي 3D فلم جوړولو اپلیکیشن دی. AI ویډیو نه جوړوي.

## د سیستم جلا برخې

### په موبایل کې
- د کاروونکي پروژې، صحنې، کرکټرونه او ماډلونه.
- د پروژې JSON او اړوند عکسونه، 3D فایلونه او غږونه.
- فلمونه او MP4 صادر شوي فایلونه.
- د اصلي اپ 3D شتمنۍ د APK دننه.

### آنلاین Cloudflare
- د کارن حساب او د Telegram د مالکیت تایید.
- د اپ او بوټ جلا Points/USDT بیلانسونه.
- د پیکونو کتالوګ، د پېرودونو او unlock اجازې.
- د حساب ناستې او د معاملو تاریخ.

### GitHub
- د اپلیکیشن سرچینه.
- GitHub Actions یوازې د APK جوړولو لپاره.
- GitHub د کاروونکو فلمونه یا 3D پروژې نه ساتي.

## د فلم جوړولو بهیر
1. نوې پروژه جوړه کړه.
2. 3D کرکټرونه، چاپېریالونه او ماډلونه جوړ یا وارد کړه.
3. صحنه جوړه کړه او توکي پکې ځای پر ځای کړه.
4. د حرکتونو کی‌فریمونه ثبت کړه.
5. کامره، رڼا، مواد او رنګونه تنظیم کړه.
6. ډیالوګ، موسیقي او غږیز اغېزونه ورزیات کړه.
7. صحنې په Timeline کې ترتیب کړه.
8. مخکتنه وکړه او اصلاحات راوړه.
9. MP4 په موبایل کې صادر او خوندي کړه.

## د معلوماتو د خوندي کولو اصول
- هره پروژه باید په موبایل کې جلا فولډر ولري.
- د فایل لارې دې د پروژې دننه نسبي وي.
- د خوندي کولو پر مهال موقتي فایل او د بېرته راګرځېدو لاره وکاروه.
- د کاروونکي فلمونه او assets کلاوډ ته مه پورته کوه.
- د حساب معلوماتو او فلم فایلونو ترمنځ هېڅ اتومات sync نشته.

## د کار اوسنی ترتیب
1. Android build او CI.
2. Telegram حساب نښلول او د بیلانس لوستل.
3. د پروژې خوندي کول او پرانیستل.
4. GLB/GLTF ماډل واردول.
5. د صحنې ایډیټر.
6. ریګ او انیمېشن.
7. Timeline، کامره، غږ او مخکتنه.
8. MP4 صادرول.

هر پړاو باید compile شي او په واقعي Android موبایل کې وازمویل شي. تر ازموینې مخکې یې بشپړ یا فعال مه ګڼئ.
