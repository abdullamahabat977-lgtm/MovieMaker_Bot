# د Movie Studio v2 د جوړولو نقشه

## ثابتې پرېکړې

- اپلیکیشن د لاسي 3D فلم جوړولو لپاره دی؛ AI ویډیو نه تولیدوي.
- اصلي 3D شتمنۍ چې د اپ له خوا برابرېږي د APK دننه ساتل کېږي.
- د کاروونکي جوړ شوي کرکټرونه، پروژې، فلمونه او صادر شوي ویډیوګانې په موبایل کې ساتل کېږي.
- Cloudflare د حساب، Telegram لینک، Points، USDT، پیکونو او اجازو معلومات ساتي؛ د فلم فایلونه نه ساتي.
- GitHub Actions یوازې APK جوړوي.

## د انجن پړاوونه

اوسنی 3D مخکتنی بنسټ OpenGL ES 2.0 دی. دا د بشپړ فلم جوړولو انجن نه دی. د انجن وروستۍ پراختیا باید د موبایل د حافظې، GPU او د GLB/GLTF ماډلونو د اړتیا له مخې په جلا پړاو کې وټاکل شي. د نوې انجن dependency تر ازموینې مخکې مه ورزیاتوئ.

## د جوړولو ترتیب

1. د Android د جوړولو بشپړ بنسټ او APK CI.
2. د حساب نښلول او د بیلانس لوستل.
3. د پروژې محلي فایل جوړول، پرانیستل او اتومات خوندي کول.
4. د 3D ماډل کتابتون او د GLB/GLTF واردول.
5. د صحنې ایډیټر او د توکو ځای پر ځای کول.
6. د کرکټر ریګ او د حرکت کی‌فریمونه.
7. کامره، رڼا، مواد او رنګونه.
8. د ډیالوګ او غږ Timeline.
9. د صحنو Timeline او مخکتنه.
10. د MP4 صادرول او د موبایل پر حقیقي وسیله ازموینه.

## د کیفیت اصول

- د کمزوري موبایل لپاره Low-poly ماډلونه او 720p لومړنی هدف.
- په هر فریم کې بې ضرورته حافظه/آبجکټونه مه جوړوئ.
- د فایل خوندي کول باید د پخوانۍ پروژې خوندي کاپي وساتي.
- هره ځانګړنه باید جلا compile او device test ولري.
- تر عملي ازموینې مخکې د حل یا بریالیتوب ادعا مه کوئ.
