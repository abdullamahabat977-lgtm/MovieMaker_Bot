# Movie Studio — د فلم سټوډیو

دا د Android اپلیکیشن پروژه ده. اصلي موخه یې دا ده چې کاروونکی خپل فلم په خپل لاس، له پیله تر پایه، په **3D بڼه** جوړ کړي. دا اپ د AI له لارې ویډیو نه جوړوي.

## د پروژې اوسنی حالت

- د اصلي پاڼې ډیزاین د 3D فلم جوړونې لپاره بدل شوی.
- ټولې برخې په پښتو او RTL ترتیب دي.
- د هرې برخې کارت جلا رنګ لري.
- د «لارښوونې» او «زموږ په اړه» برخې د معلوماتو کړکۍ پرانیزي.
- د 3D جوړونې نور وسایل اوس د راتلونکو پړاوونو لپاره د اصلي پاڼې د ننوتلو ځایونه دي؛ تر اوسه یې بشپړ 3D انجن او د فلم صادرولو سیستم نه دی نښلول شوی.

## د 3D فلم جوړولو وړاندیز شوی پړاوونه

1. نوې پروژه: د فلم نوم، د تصویر اندازه او د فریمونو کچه ټاکل.
2. 3D کرکټرونه: ماډل واردول یا جوړول، بڼه او جامې تنظیمول.
3. چاپېریال او صحنې: ځمکه، ودانۍ، شیان، اسمان او نور عناصر برابرول.
4. حرکت: د کرکټر هډوکي/ریګ، حرکتونه او کی‌فریمونه تنظیمول.
5. کمره او رڼا: د لید زاویه، زوم، سیوري او د رڼا سرچینې ټاکل.
6. غږ: ډیالوګ، موسیقي او اغېزیز غږونه په خپل وخت برابرول.
7. مهال‌وېش: صحنې، حرکتونه او غږونه سره همغږي کول.
8. مخکتنه او صادرول: فلم کتل او په MP4 بڼه یې خوندي کول.

## د JPG شالید عکس

1. خپل عکس په JPG بڼه وساتئ.
2. د عکس نوم باید داسې وي: `poster_background.jpg`
3. عکس دې فولډر ته واچوئ:

   `app/src/main/res/drawable/poster_background.jpg`

4. په `MainActivity.kt` کې د عکس کوډ:

   `setBackgroundResource(R.drawable.poster_background)`

په کوډ کې د `.jpg` لیکل نه کېږي؛ د سرچینې نوم `R.drawable.poster_background` وي.

## په Code on the Go کې د GitHub بدلونونه راوستل

که پروژه دې لا په موبایل کې موجوده وي:

1. په Code on the Go کې هماغه پروژه پرانیزه.
2. د سکرین له لاندې برخې پورته سوایپ وکړه.
3. د **Git** برخه پرانیزه.
4. د **Pull** تڼۍ ووهه، څو د GitHub د `main` څانګې وروستي بدلونونه موبایل ته راشي.

**Pull** د GitHub بدلونونه موبایل ته راولي. **Push** د موبایل بدلونونه GitHub ته لېږي.

## مهم تخنیکي یادښت

د ریښتیني 3D لید، ماډلونو او انیمېشن لپاره باید په راتلونکي پړاو کې د Android له پروژې سره مناسب 3D رینډر انجن ونښلول شي. د دې لپاره باید د پروژې Gradle فایلونه او د موبایل د حافظې/سرعت محدودیتونه لومړی وکتل شي. تر هغه مخکې د اصلي پاڼې کارتونه یوازې د برخو د پرانیستلو ځایونه دي.

په دې ذخیره کې اوس د اصلي پاڼې Kotlin فایل او لارښود شامل دي. د بشپړې Android پروژې ټول فایلونه، د شالید عکس او د جوړولو تنظیمات باید هم موجود وي، څو APK په بریالیتوب جوړ شي.
