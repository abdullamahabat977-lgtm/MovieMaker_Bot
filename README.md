# Movie Studio — د فلم سټوډیو

دا د Android اپلیکیشن پروژه ده. اصلي موخه یې دا ده چې کاروونکی خپل فلم په خپل لاس، له پیله تر پایه، په **3D بڼه** جوړ کړي. دا اپ د AI له لارې ویډیو نه جوړوي.

## د پروژې اوسنی حالت

- د اصلي پاڼې ډیزاین د 3D فلم جوړونې لپاره بدل شوی.
- ټولې برخې په پښتو او RTL ترتیب دي.
- د هرې برخې کارت جلا رنګ لري.
- د «لارښوونې» او «زموږ په اړه» برخې د معلوماتو کړکۍ پرانیزي.
- د 3D جوړونې نور وسایل اوس د راتلونکو پړاوونو لپاره د اصلي پاڼې د ننوتلو ځایونه دي؛ تر اوسه یې بشپړ 3D انجن او د فلم صادرولو سیستم نه دی نښلول شوی.

## د 3D فلم جوړولو وړاندیز شوی پړاوونه

1. نوې پروژه: د فلم نوم، د تصویر اندازه او د فریمونو کچه ټاکل.
2. 3D کرکټرونه: ماډل واردول یا جوړول، بڼه او جامې تنظیمول.
3. چاپېریال او صحنې: ځمکه، ودانۍ، شیان، اسمان او نور عناصر برابرول.
4. حرکت: د کرکټر هډوکي/ریګ، حرکتونه او کی‌فریمونه تنظیمول.
5. کمره او رڼا: د لید زاویه، زوم، سیوري او د رڼا سرچینې ټاکل.
6. غږ: ډیالوګ، موسیقي او اغېزیز غږونه په خپل وخت برابرول.
7. مهال‌وېش: صحنې، حرکتونه او غږونه سره همغږي کول.
8. مخکتنه او صادرول: فلم کتل او په MP4 بڼه یې خوندي کول.

## د JPG شالید عکس

1. خپل عکس په JPG بڼه وساتئ.
2. د عکس نوم باید داسې وي: `poster_background.jpg`
3. عکس دې فولډر ته واچوئ:

   `app/src/main/res/drawable/poster_background.jpg`

4. په `MainActivity.kt` کې د عکس کوډ:

   `setBackgroundResource(R.drawable.poster_background)`

په کوډ کې د `.jpg` لیکل نه کېږي؛ د سرچینې نوم `R.drawable.poster_background` وي.

## په Code on the Go کې د GitHub بدلونونه راوستل

که پروژه دې لا په موبایل کې موجوده وي:

1. په Code on the Go کې هماغه پروژه پرانیزه.
2. د سکرین له لاندې برخې پورته سوایپ وکړه.
3. د **Git** برخه پرانیزه.
4. د **Pull** تڼۍ ووهه، څو د GitHub د `main` څانګې وروستي بدلونونه موبایل ته راشي.

**Pull** د GitHub بدلونونه موبایل ته راولي. **Push** د موبایل بدلونونه GitHub ته لېږي.

## مهم تخنیکي یادښت

د ریښتیني 3D لید، ماډلونو او انیمېشن لپاره باید په راتلونکي پړاو کې د Android له پروژې سره مناسب 3D رینډر انجن ونښلول شي. د دې لپاره باید د پروژې Gradle فایلونه او د موبایل د حافظې/سرعت محدودیتونه لومړی وکتل شي. تر هغه مخکې د اصلي پاڼې کارتونه یوازې د برخو د پرانیستلو ځایونه دي.

په دې ذخیره کې اوس د اصلي پاڼې Kotlin فایل او لارښود شامل دي. د بشپړې Android پروژې ټول فایلونه، د شالید عکس او د جوړولو تنظیمات باید هم موجود وي، څو APK په بریالیتوب جوړ شي.


## د اوسني نسخې روښانه حالت او محدودیتونه

دا برخه په قصدي ډول لیکل شوې، څو هېڅ کاروونکی د نیمګړو ځانګړنو په اړه غلط تصور ونه کړي.

### اوس فعاله ځانګړنې
- د پښتو اصلي پاڼه او د ۱۵ برخو د ننوتلو کارتونه.
- د 3D کرکټرونو لپاره د نوم، بدن، پوستکي، جامو او ویښتانو د معلوماتو ثبت.
- د چمتو کرکټرونو د نمونو ثبت او د خوندي شوو کرکټرونو لېست، کتنه او حذف.
- د 3D چاپېریال لپاره د نوم، ځای، وخت او هوا معلومات ثبتول.
- د چمتو چاپېریالونو ثبت، لېست، کتنه او حذف.
- د OpenGL ES 2.0 له لارې یو ساده، ټیټ‌پولي 3D مخکتنی لید؛ ګوته پرې کش کول د لید زاویه اړوي.
- د کرکټر او چاپېریال ثبت شوي معلومات په موبایل کې د SharedPreferences په JSON بڼه ساتل کېږي.

### لا نه دي بشپړ شوي
- ثبت شوی کرکټر اوس مهال د ریښتیني جلا 3D ماډل فایل نه دی؛ د 3D مخکتنه یو عمومي جوړ شوی کرکټر ښيي.
- ثبت شوی چاپېریال اوس مهال د صحنې بشپړ فایل نه دی؛ مخکتنه د څو ساده 3D شکلونو له لارې جوړېږي.
- د 3D ماډل واردول، هډوکي/ریګ، حقیقي انیمېشن او کی‌فریمونه لا نه دي جوړ شوي.
- د کمرې، رڼا او موادو بشپړ کنټرول لا نه دی جوړ شوی.
- د غږ ثبت/ایډیټ، مهال‌وېش، د فلمونو بشپړ پروژه‌یي مدیریت او MP4 صادرول لا نه دي جوړ شوي.
- د اصلي پاڼې هغه کارتونه چې پورته د فعالو ځانګړنو په لېست کې نه دي، لا بشپړ کاري وسایل نه دي.

### د زور بندېدو او 3D مخکتنې لپاره تازه محافظتي بدلونونه
- د OpenGL د پیل او هر فریم تېروتنې اوس نیول کېږي، څو د ګرافیک ډرایور/Shader ستونزه د اپ ټول پروسې ته د غورځېدو لامل نه شي.
- د EGL رنګ تنظیم بدل شوی، څو د زړو موبایلونو له هغو ګرافیکي ډرایورونو سره سازګاري زیاته شي چې Alpha چینل نه لري.
- د اپ د Pause/Resume پر مهال د 3D مخکتنې ژوند‌دورې ته پام کېږي.
- د کرکټرونو او چاپېریالونو د خوندي کولو پایله اوس کتل کېږي؛ که ثبت ناکام شي، کاروونکي ته د ناکامۍ خبر ورکول کېږي.
- د خوندي چاپېریال د ځای نومونه د مخکتنې له صحنې سره په پراخ ډول پېژندل کېږي.

**مهم:** دا محافظتي بدلونونه د کوډ له مخې د احتمالي ستونزو مخه نیسي، خو د ستا په موبایل کې د APK عملي ازموینه لا نه ده شوې. د زور بندېدو اصلي علت تر هغه قطعي نه شي بلل کېدای، څو د Android د `FATAL EXCEPTION` یا `AndroidRuntime` د تېروتنې لاګ ونه کتل شي.

### د GitHub ذخیرې د جوړولو نیمګړتیا
په دې GitHub ذخیره کې د Kotlin او Java سرچینې او اسناد شته، خو د بشپړې Android پروژې د جوړولو فایلونه لکه `settings.gradle`، `build.gradle`، `AndroidManifest.xml`، د Gradle wrapper او د `res` سرچینې لا ټولې نه دي ثبت شوې. له همدې امله یوازې له دې ذخیرې څخه د APK جوړېدل لا نه شي تاییدېدای. د موبایل په Code on the Go کې شته اصلي پروژه مه حذفوه.
