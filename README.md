# Movie Studio — د فلم سټوډیو

دا د Android اپلیکیشن پروژه ده. موخه یې دا ده چې کاروونکی خپل فلم په لاس جوړ کړي؛ دا اپ د AI له لارې فلم نه جوړوي.

## د اصلي پاڼې د JPG شالید عکس

1. خپل عکس په JPG بڼه وساتئ.
2. د عکس نوم باید په همدې ډول وي: `poster_background.jpg`
3. عکس د Android پروژې دې فولډر ته واچوئ:

   `app/src/main/res/drawable/poster_background.jpg`

4. د عکس نوم ټول په کوچنیو انګلیسي تورو ولیکئ؛ تش ځایونه او نښې مه کاروئ.
5. په `MainActivity.kt` کې د عکس کوډ داسې دی:

   `setBackgroundResource(R.drawable.poster_background)`

یادونه: په کوډ کې د `.jpg` لیکل نه کېږي؛ Android د فایل له نومه `R.drawable.poster_background` جوړوي. د فایل نوم او د کوډ نوم باید یو شان وي.

## په Code on the Go کې د GitHub بدلونونه راوستل

که پروژه دې لا په موبایل کې موجوده وي:

1. په Code on the Go کې هماغه پروژه پرانیزه.
2. د سکرین له لاندې برخې پورته سوایپ وکړه.
3. د **Git** برخه پرانیزه.
4. د **Pull** تڼۍ ووهه، څو د GitHub د `main` څانګې وروستي بدلونونه موبایل ته راشي.

**Pull** د GitHub بدلونونه موبایل ته راولي. **Push** بیا د موبایل بدلونونه GitHub ته لېږي؛ دا دواړه سره مه ګډوئ.

## مهمه یادونه

په دې ذخیره کې د `MainActivity.kt` سرچینه او دا لارښود ثبت دي. د بشپړې Android پروژې ټول فایلونه او د JPG عکس باید هم په پروژه کې موجود وي، څو اپلیکیشن جوړ او اجرا شي.
