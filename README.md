# Movie Studio (Android)

A personal, offline-first Android movie-making studio built with Kotlin.

> This repository stores the Android application source code. Despite the repository name `MovieMaker_Bot`, this project is **not a Telegram bot**.

## Project goals

- Build films manually; no AI-generated video.
- Create and manage characters.
- Design scenes and backgrounds.
- Set character movements and actions.
- Add dialogue, camera settings, sound and music.
- Edit scenes and export finished movies as MP4.
- Keep the app interface in Pashto with right-to-left (RTL) layout.
- Prioritize offline use and compatibility with modest Android devices.

## Development environment

- IDE: Code on the Go (Android)
- Language: Kotlin
- Package: `com.moviestudio.filmmaker`
- Minimum Android SDK: API 23
- Build variant: Debug APK
