# Movie Studio — د فلم سټوډیو

دا د Android لپاره د لاسي فلم جوړولو اپلیکیشن پروژه ده. موخه دا ده چې کاروونکی له انټرنېټ پرته خپل کرکټرونه، صحنې، حرکتونه، ډیالوګونه، کامره او غږونه پخپله تنظیم کړي او فلمونه سره یوځای کړي. آنلاین AI خدمت د دې پروژې شرط نه دی.

## د 2D او 3D پرېکړه

**د اپلیکیشن وروستی 2D، 3D یا ګډ شکل لا د کاروونکي له خوا نه دی تایید شوی.** په ذخیره کې موجود 3D مخکتنی کوډ او د 3D سټوډیو ځینې پردې یوازې ازمایښتي نمونه ده؛ دا د ټول اپلیکیشن وروستۍ پرېکړه نه ګڼل کېږي. تر تایید مخکې به د پروژې اصلي معلومات او کاري بهیر د دواړو لپاره بې‌طرفه ساتل کېږي.

د ګډ فلم جوړولو د بهیر او معلوماتي جوړښت لپاره وګورئ: [د پروژې کاري نقشه](docs/PROJECT_WORKFLOW.md).

## د پروژې اوسنی حالت

### په موجوده کوډ کې شته
- د پښتو او RTL اصلي پاڼې جوړښت.
- د کرکټر او چاپېریال د معلوماتو د ثبت ځینې ازمایښتي فورمې.
- د کرکټرونو او چاپېریالونو د معلوماتو محلي ساتل د `SharedPreferences` او JSON له لارې.
- د OpenGL ES 2.0 یو ساده 3D مخکتنی لید؛ د ګوتې په کشولو د لید زاویه بدلېږي.
- د JPG شالید عکس د سرچینې نوم `poster_background` دی.

### لا بشپړ شوي فلمي وسایل نه دي
- د 2D/3D یا ګډ وروستي سیستم پرېکړه او بشپړ تطبیق.
- د حقیقي کرکټر ماډلونه، د هډوکو/بندونو سیستم او بشپړ حرکتونه.
- د کی‌فریمونو مهال‌وېش او د حرکت ایډیټ.
- د کامرې بشپړ کنټرول.
- د ډیالوګ ثبت، موسیقي او غږیز ټریکونه.
- د څو صحنو Timeline او بشپړ Preview.
- د MP4 فلم صادرول.

د 3D ازمایښتي کوډ په اړه جلا یادښت: [3D ازمایښتي نقشه](3D_ROADMAP.md).

## د اصلي پاڼې د JPG عکس

1. د عکس نوم دې `poster_background.jpg` وي.
2. عکس دې دې ځای ته واچول شي:

   `app/src/main/res/drawable/poster_background.jpg`

3. په Kotlin کې د سرچینې نوم داسې کارول کېږي:

   `setBackgroundResource(R.drawable.poster_background)`

په کوډ کې د `.jpg` لیکل نه کېږي.

## په Code on the Go کې د GitHub بدلونونه راوستل

که اصلي پروژه دې په موبایل کې پرانیستې وي:

1. د سکرین له لاندې برخې پورته سوایپ وکړه.
2. د **Git** ټب پرانیزه.
3. **Pull** ووهه، څو د GitHub د `main` څانګې بدلونونه موبایل ته راشي.

**Pull** د GitHub بدلونونه موبایل ته راوړي؛ **Push** د موبایل Commit شوي بدلونونه GitHub ته لېږي. د پروژې اصلي محلي فولډر مه حذفوه.

## د GitHub ذخیرې مهم محدودیت

د دې ذخیرې اوسنی فایل‌لړ د بشپړې Android پروژې ټول فایلونه نه لري. د Gradle اصلي تنظیمات، Manifest، د سرچینو ټول فایلونه او نور اړین جوړښتي فایلونه لا نه دي ټول ثبت شوي. له همدې امله یوازې د GitHub له دې ذخیرې څخه د APK د جوړېدو ادعا نه کېږي. په Code on the Go کې هغه محلي پروژه وساته چې مخکې دې APK ترې جوړ کړی دی.

## د راتلونکي عملي کار ترتیب

1. د پروژې نوم، تنظیمات او محلي خوندي کول.
2. د کرکټرونو، چاپېریالونو او نورو توکو کتابتون.
3. صحنې او د توکو ځای پر ځای کول.
4. مهال‌وېش او د فریمونو حساب.
5. حرکتونه او کی‌فریمونه.
6. کامره، ډیالوګ او غږونه.
7. مخکتنه او د صحنو یوځای کول.
8. د موبایل له وړتیا سره سم MP4 صادرول.

دا ترتیب عمومي پلان دی؛ د 2D/3D وروستی انتخاب تر تایید مخکې نه ټاکي.
